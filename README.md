# EVCA (Enterprise Value Chain Architect)

EVCA is an analysis app that turns fragmented business friction into a structured value-chain diagnosis, prioritized transformation roadmap, and executive-ready strategic report.

It structures complex operational problems into inspectable artifacts that connect business reality, systems, ownership, metrics, and action.

## What EVCA does

EVCA helps users:
- capture current-state operating friction
- define a target future state
- map primary activities across the value chain
- identify gaps across people, technology, governance, and finance
- prioritize transformation initiatives
- generate a final operating-model assessment

## Workflow

EVCA runs through five phases:

1. **Basics & Strategy**
2. **Value Chain Mapping**
3. **Support Gaps**
4. **Roadmap & Fixes**
5. **Final Report**

## Output Artifacts

EVCA produces:
- value-chain stage maps
- operating-model assessments
- transformation roadmaps
- final strategic reports
